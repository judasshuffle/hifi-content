# DarkRide Classic Chat (experimental)

Original High Fidelity domain-local public chat, hosted for one-URL loading in DarkRide.

## Start

In DarkRide, choose **Running Scripts → Load Script from URL** and paste:

https://raw.githubusercontent.com/judasshuffle/hifi-content/master/darkride-classic-chat/chat.js

The HTML companion lives at `html/ChatPage.html` beside the script.

This is **not private or cross-domain chat**. Avoid loading the script twice as this can duplicate messages. The legacy script was tested locally in DarkRide; loading from this GitHub URL still needs a viewer test.
