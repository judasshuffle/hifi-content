# DarkRide Chat 2.0 — visual preview

Separate experimental styling of the original High Fidelity domain-local chat. **The classic chat remains untouched.**

## One URL to load

In DarkRide: **Edit → Running Scripts → Load Script from URL**, paste:

https://raw.githubusercontent.com/judasshuffle/hifi-content/master/darkride-chat-v2/chat.js

Stop any existing classic chat script first to prevent duplicate messages. The script loads the companion page `html/ChatPage.html` from this same folder.

Features: dark compact interface, timestamps, coloured sender names, font controls, Send button, clear log, and preserved avatar interactions and speech bubbles. **Public domain chat only; no private messages.**

**Status:** Uploaded and source-checked, but not yet tested in a running DarkRide viewer. Please test before sharing widely.
